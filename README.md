# RavenEmuDSK

Application **C++20** pour **Windows, Linux et macOS**, propulsée par [RavenCore](https://github.com/GhostPunishR/RavenCore). Interface inspirée du projet [Retrophora-Emulateur](https://github.com/Retrophora/Retrophora-Emulateur), avec les couleurs de [RavenEmu](https://github.com/GhostPunishR/RavenEmu) et des succès **RetroAchievements** officiels, sans succès locaux Retrophora.

> Projet en cours de portage. La présence des fichiers et des workflows ne garantit pas encore une application compilée ou jouable sur les trois systèmes.
